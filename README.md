# NftCatchment

Syncs Non-Fungible Token (NFT) metadata with a catchment area to provide a centralized view for collectors and artists.

With NftCatchment, you get a lightweight tool that stays out of your way.

**What you get**

- Syncs Non-Fungible Token (NFT) metadata
- with a catchment area to
- provide a centralized view for

- javascript

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/NftCatchment.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

To configure NftCatchment, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
